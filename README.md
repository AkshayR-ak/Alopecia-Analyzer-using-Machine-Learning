# Alopecia Analyzer using Machine Learning

A machine learning-based web application for detecting Alopecia Areata from scalp images.

## Installation

```bash
git clone https://github.com/AkshayR-ak/Alopecia-Analyzer-using-Machine-Learning.git
cd Alopecia-Analyzer-using-Machine-Learning
pip install -r requirements.txt
streamlit run app.py
